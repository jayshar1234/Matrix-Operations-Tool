# Matrix-Operations-Tool
Matrix operations tool helps the user to perform operation on matrices.

#How to setup in the local system
1. Install python in the system.
2. Install numpy and flask using :- pip install flask numpy.
3. For the site to be active install live server in vs code.

#Tech stack
matrix operations tool uses 
1. Html,css,js for ui.
2. Flask and numpy for backend and to perform mathematical and numerical operations on the input provied by the user.

#Structure
This tool uses javascript for the input and then flask convert that input to perform operation using numpy. The operation that the user can perform are additon, subtraction, multiplication, transpose, determinant on the martices provide my the user.

#How to run the application
After install all the tech provided in the setup guide.

1. In the terminal write python operation.py and enter the flask server will go online and connect with the pages of the application.
2. Then hit the go live button to open the application in browser.
3. Then enter the number of rows and coloumn for both matrices.
4. After that inserting the input in both matrices and selecting the operation the output will be appear on the site.
